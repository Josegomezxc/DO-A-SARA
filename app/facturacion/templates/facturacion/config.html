    El RUC 9999999999999 es un placeholder: el SRI rechazará la certificación del emisor hasta configurar el RUC y la firma reales.

    Cómo funciona

    1. En el POS, el vendedor activa "¿Cliente pide factura?" y carga los datos del receptor.
    2. Al completar el pedido, el sistema genera y firma el XML y lo envía al SRI.
    3. Si el SRI no responde, el comprobante queda pendiente y se reintenta con python manage.py facturacion_pendientes (puede programarse como tarea periódica).
    4. La autorización se consulta automáticamente; si queda en proceso, se consulta después.
